# Agentic Eclipse Library plugin — privacy policy

Publisher: Pere Guerra Serra. Effective date: 16 October 2026.

This policy covers the Agentic Eclipse Library desktop plugin and its bundled local Python engine.
It does not replace the policies of the AI application, package registry, reference-data provider or
website that you choose to use.

## Information processed and purposes

The plugin processes the eclipse photographs, calibration files, recipes and output locations selected
for your task. These can contain filenames, local paths, capture times, exposure and camera metadata,
and observation information supplied for scientific calculations. A local path can contain a person's
name. Use only the information needed for calibration, stacking, visualisation or comparison; remove
unneeded personal metadata from material you choose to share.

The bundled engine reads these inputs and writes images, arrays, reports and provenance records locally.
It has no telemetry, advertising, account system, credential reader or automatic upload service. The
publisher does not receive your photographs, prompts or processing results through the plugin.

## Recipients and network use

- Your AI host may process prompts, file names, selected previews and tool outputs that enter the chat.
  Its own account settings and privacy policy govern that processing. Local numerical processing does
  not mean that an AI conversation is offline.
- Installing dependencies normally contacts PyPI and its distribution infrastructure. Downloading
  authorised public reference data contacts the named scientific data provider. Astropy may retrieve
  Earth-orientation tables when network access is enabled. These services receive ordinary network
  request information, such as the connecting IP address and requested resource, under their policies.
- If you choose to post a GitHub issue, the content and your GitHub profile are visible to GitHub, the
  project maintainer and, in this public repository, other readers. Do not post private photographs,
  credentials or personal information in a support issue.

The plugin does not sell personal data, send it to advertisers or build user profiles.

## Retention and controls

Local inputs, outputs and provenance records remain on your computer until you remove them using your
own file controls. The plugin has no automatic retention deadline and does not automatically delete
your originals. The publisher has no server-side copy of local processing data to retain or erase.

You control which files are selected, which results enter the chat, whether a network download is
authorised, and whether anything is published. You can restrict the AI host's file and network access,
use synthetic examples, remove local outputs, or uninstall the plugin. Manage chat retention through
the AI host's controls. Public support contributions remain on GitHub until removed through GitHub's
controls; copies, platform records or caches may remain under GitHub's own policy.

For a privacy question, use [GitHub Issues](https://github.com/PeterWar/Agentic-Eclipse-Library/issues)
without including the private data itself. The current policy is maintained at this URL; changes will
be dated in the repository history.
