# Desktop applications

[Eclipse Image Processor](eclipse-image-processor/README.md) is an optional Python/PySide6 desktop application contributed by Francisco Bitto. It provides interactive independent corona-filter layers, background gradient equalization and 16-bit TIFF/Photoshop export.

It is a standalone application with its own environment, dependencies and tests. It does not replace AEL's command-line tools, change their defaults or become part of the AEL runtime installation. Its AEL-derived numerical code is bundled and attributed; it does not dynamically call the installed AEL package.

See its [contribution scope](eclipse-image-processor/UPSTREAM_CONTRIBUTION.md), [technical documentation](eclipse-image-processor/docs/README.md) and [licence/attributions](eclipse-image-processor/ATTRIBUTIONS.md).
